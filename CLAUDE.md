# UT99 Cow Skins — Project Instructions

BP1H / BP4H bonus-pack skin handlers that restore the Bonus Pack 1
(Nali WarCow, Nali, Skaarj Hybrid) and Bonus Pack 4 (War Boss, Xan Mark II)
player models on servers running modern InstaGibPlus (IG+).

This is a standalone git repo. Global rules live in `~/.claude/CLAUDE.md`; the
UT99 shared rules live in `..\CLAUDE.md`. Do not duplicate those here.

## Key Files

| File | Purpose |
|---|---|
| `BPHandlers\build.bat` | Compiles both handlers against a specific IG+ build; derives package names from the IG+ version. |
| `BPHandlers\README.md` | Full build + server-install instructions and port notes. |
| `BPHandlers\Source\BP1H\Classes\BP1LoginHandler.uc` | IG+ `PlayerPacks` login handler for Bonus Pack 1 models. |
| `BPHandlers\Source\BP1H\Classes\bbCustomPlayer.uc` | Base netcode-enhanced player class for the BP1 models. |
| `BPHandlers\Source\BP1H\Classes\bbTCow.uc` | Nali WarCow (`MultiMesh.TCow`) handler class. |
| `BPHandlers\Source\BP1H\Classes\bbTNali.uc` | Nali handler class. |
| `BPHandlers\Source\BP1H\Classes\bbTSkaarj.uc` | Skaarj Hybrid handler class. |
| `BPHandlers\Source\BP4H\Classes\BP4LoginHandler.uc` | IG+ `PlayerPacks` login handler for Bonus Pack 4 models. |
| `BPHandlers\Source\BP4H\Classes\bbSkeletal.uc` | Base class for the SkeletalChars BP4 models. |
| `BPHandlers\Source\BP4H\Classes\bbWarBoss.uc` | War Boss (`SkeletalChars.WarMachineBoss`) handler class. |
| `BPHandlers\Source\BP4H\Classes\bbXanMK2.uc` | Xan Mark II (`SkeletalChars.NewXan`) handler class. |
| `BPHandlers\Output\` | Build output (git-ignored, regenerated by `build.bat`). Current build: `BP1Hnext-netcode-ef237853.u` / `BP4Hnext-netcode-ef237853.u` (+ matching `.uz` for the redirect). |

## Project-Specific Notes

- The handler package names are **derived from the IG+ `PackageVersion`**:
  `BP1H<PackageVersion>` / `BP4H<PackageVersion>`. Every IG+ update that
  changes that string requires a rebuild and updated `ServerPackages` lines.
  See `MEMORY.md` for the current target version.
- Building requires a local UT99/469 install with `ucc.exe` plus the full IG+
  release System file set copied into `<UT>\System` — the single IG+ `.u` is
  not enough. Full file list is in `README.md`.
- IG+ release binaries (`InstaGibPlus_*.u`/`.uz`) are compile **inputs**, not
  source, and are git-ignored.
